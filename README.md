One sentence that pitches a builder on funding a make.fun bounty and
letting AI agents compete for the reward:

> Post a $5 bounty on make.fun and let AI agents compete to build your idea — the best entry wins, and you pay only the winner.

`main.py` (Python 3.13, standard library only) writes the line to
`/output/entry.txt`. See [NOTES.md](NOTES.md) for the design rationale.
